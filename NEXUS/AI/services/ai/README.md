# NEXUS-NER — AI/ML Service

Intelligence layer for the NEXUS-NER logistics risk management system.

> ⚠️ **Prototype Notice**: This service is trained on **synthetic data** generated for
> prototype and demonstration purposes. Do **not** present model metrics as real-world
> accuracy. Replace synthetic data with real operational data before production deployment.

---

## Architecture

```
DATA SOURCES (Weather, Roads, Incidents)
           ↓
   DATA PREPROCESSING
           ↓
   FEATURE ENGINEERING
           ↓
   DISRUPTION MODEL (Random Forest)
           ↓
       PROBABILITY
           ↓
      RISK ENGINE  ←── Weather + Road + Traffic + History + Accessibility
           ↓
  ┌────────┴────────┐
  │                 │
EXPLAINABILITY   ROUTE INTELLIGENCE
  │                 │
  └────────┬────────┘
           ↓
     RECOMMENDATION
           ↓
       BACKEND API
           ↓
      WEB / MOBILE
```

## Setup

```bash
# 1. Create and activate virtual environment (Python 3.10+)
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS

# 2. Install dependencies
pip install -r services/ai/requirements.txt

# 3. Navigate to the AI service root
cd services/ai
```

## Running the Full Pipeline

### Step 1 — Generate Dataset

```bash
python data/generate_dataset.py
```

Output: `data/processed/dataset.csv` (10,000 rows)

### Step 2 — Train Model

```bash
python training/train.py
```

Output:
- `models/risk_model.pkl` — trained Random Forest pipeline
- `models/model_metadata.json` — metrics + disclaimer
- `models/confusion_matrix.png` — confusion matrix plot

### Step 3 — Evaluate Model

```bash
python training/evaluate.py
```

Prints full classification report with Accuracy, Precision, Recall, F1, ROC-AUC.

### Step 4 — Run Tests

```bash
pytest tests/ -v
```

Tests that require a trained model are automatically skipped if the model is not yet trained.

### Step 5 — Start API

```bash
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

API docs available at: **http://localhost:8000/docs**

### Step 6 — Interactive Web Testing Suite

Open `frontend/index.html` in any browser to access the 9-tab testing interface:
- **Health Check & Latency Monitor**
- **Live Feature Transformer Playground**
- **Disruption Prediction & Explainability**
- **Multi-Signal Risk Formula Breakdown**
- **Route Intelligence & Corridor Matrix**
- **Decision Engine with Emergency Medical Logic**
- **7-Scenario Simulation Lab**
- **Model Evaluation & Metrics Table**
- **In-Browser Automated Endpoint Test Suite**

### `POST /ai/predict-risk`

Predict disruption risk for a road segment.

```bash
curl -X POST http://localhost:8000/ai/predict-risk \
  -H "Content-Type: application/json" \
  -d '{
    "road_id": "NH13_042",
    "features": {
      "rainfall_1h": 90,
      "rainfall_3h": 210,
      "traffic_level": 0.75,
      "road_condition": 0.3,
      "slope": 18,
      "river_distance": 0.9,
      "historical_incidents": 7
    }
  }'
```

**Response:**
```json
{
  "road_id": "NH13_042",
  "probability": 0.82,
  "risk_level": "HIGH",
  "final_risk": 0.74,
  "factors": [
    "Heavy rainfall (90 mm/h)",
    "Poor road condition (score: 0.30)",
    "High historical incident frequency (7 incidents)"
  ],
  "components": {
    "ml_probability": 0.82,
    "weather_risk": 0.78,
    "road_condition_risk": 0.69,
    "traffic_risk": 0.54,
    "historical_risk": 0.42,
    "accessibility_penalty": 0.51
  }
}
```

## Risk Score Formula

```
final_risk =
    0.40 × ml_probability
  + 0.20 × weather_risk
  + 0.15 × road_condition_risk
  + 0.10 × traffic_risk
  + 0.10 × historical_risk
  + 0.05 × accessibility_penalty
```

| Range     | Category |
|-----------|----------|
| 0.00–0.25 | SAFE     |
| 0.25–0.50 | MODERATE |
| 0.50–0.75 | HIGH     |
| 0.75–1.00 | CRITICAL |

## Action Thresholds

| Risk      | Standard Cargo | Emergency/Medical |
|-----------|---------------|-------------------|
| < 30%     | MONITOR       | MONITOR (< 20%)   |
| 30–55%    | WARN          | WARN (20–40%)     |
| 55–78%    | REROUTE       | REROUTE (40–65%)  |
| ≥ 78%     | BLOCK_ROUTE   | ESCALATE          |

## Key Technical Decisions

| Decision | Choice | Reason |
|---|---|---|
| Primary model | Random Forest | Reliable, explainable, handles mixed data well |
| Baseline model | Logistic Regression | Simple interpretable baseline |
| Class imbalance | `class_weight="balanced"` | Avoids ignoring minority disruption class |
| Priority metric | Recall | Missing a real disruption is worse than a false alarm |
| Explainability | Feature importance × input | Fast, no extra dependency; SHAP optional |
| API framework | FastAPI | Modern, async, OpenAPI docs built-in |
| Data | Synthetic | Real data not available for prototype |
